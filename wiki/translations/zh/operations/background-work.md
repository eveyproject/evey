# 后台任务与服务器负载

除了播放之外，服务器还会运行自己的任务：扫描媒体库、获取图片、生成进度条的缩略图、检测片头和片尾、分析文件（关键帧、编码级别、媒体健康）。本页说明这些任务如何与正在观看的人共享机器。

## 播放优先

后台任务使用处理器的一部分，默认 **25 %**（**Admin → 服务器配置 → 分配的算力**）。**50 %** 会让它们更快，适合没有人使用服务器的时候；重型任务（媒体分析、缩略图、片头检测、分类）可以单独分配一份。更改对下一个处理的项目生效。

无论分配多少，有人观看时后台任务都会暂停，之后再继续。因此在一个新的媒体库上，如果服务器正在使用中，缩略图和片头标记会在几个小时而不是几分钟内陆续出现。

## 后台运行的任务

| 任务 | 提供的内容 | 何时运行 |
| --- | --- | --- |
| 媒体库扫描 | 新增、修改和删除的文件 | 文件变化时、按计划、在开启时于启动时运行。见[媒体库与元数据](../administration/libraries.md)。 |
| 图片下载 | 以 WebP 格式保存在服务器上的海报和背景图 | 扫描期间；缺失的每小时重试一次。关闭时：图片由浏览器从互联网加载，有些浏览器会阻止这样做。 |
| 进度条缩略图 | 拖动进度条时显示的预览（每 7 秒一张图） | 添加条目时，以及启动时为缺少缩略图的条目生成。可以在 **服务器配置** 中关闭。 |
| 片头和片尾检测 | **跳过片头** 和 **跳过片尾** 按钮 | 持续运行，针对社区数据库未覆盖的条目 |
| 关键帧索引和编码级别 | 直接播放和不重新编码的直接复制，正确的颜色 | 持续运行，针对在收集这些信息之前扫描的文件 |

## 内存

**内存配置**（**Admin → 服务器配置**）：**低** 会挂起空闲的插件以节省内存，并在需要时唤醒它们。**自动** 在内存少于 3 GB 的机器上选择低。

## 启动时读取的设置

少数设置只在服务器启动时读取一次：保存它们会记录你的选择，重启后才会应用。面板会在它们旁边注明。它们是 **后台工作** 卡片（关键帧和编码级别处理的暂停与节奏）、**片头跳过提供商** 开关，以及转码的 **高级限制**。
