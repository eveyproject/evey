# 远程访问与 HTTPS

在家庭之外访问服务器涉及两件不同的事：Evey 前面的一个公网 HTTPS 地址，以及 Evey 自身的远程访问设置，它决定是否为你的网络之外的客户端提供服务。

## 远程访问根据公网地址决定

除非你已经自己做出选择，Evey 会在启动时决定远程访问：

- 如果给服务器设置了公网地址（`EVEY_SERVER_BASE_URL` 或 `EVEY_REMOTE_ACCESS_EXTERNAL_URL`），远程访问**开启**；
- 否则它**关闭**，只为你的本地网络中的客户端提供服务。

一旦你在 **Admin → 远程访问** 中更改了这项设置，你的选择就会被保留，服务器不再自行推断：一台已发布的服务器也可以按你的意愿只在本地网络中使用。

远程访问关闭时，本地网络之外的客户端在每个页面上都会收到 `403`，应用会显示一条说明远程访问已禁用的消息，而不是一个笼统的错误。如果服务器可以从互联网访问而远程访问是关闭的，管理页面会显示 **所有远程用户均已被锁定**，服务器会在启动时记录这一点，并记录每次拒绝及客户端地址，`evey admin doctor` 也会把它报告为失败。

远程访问是关于谁能连到服务器的选择，而不是一种保护：每个页面仍然需要登录。

## 设置

**Admin → 远程访问**。每项设置无需重启即可生效：网络设置在下一个请求时生效，码率在下一次播放时生效。

| 设置 | 效果 |
| --- | --- |
| **启用远程访问** | 开启：本地网络之外的客户端和其他客户端一样得到服务。关闭：它们收到 `403`。 |
| **外部 URL** | 公网地址。电子邮件中的链接、单点登录的重定向和流媒体 URL 都由它构建。`https://` 地址还会开启 HTTPS 模式（见下文）。 |
| **受信任的代理** | Evey 会相信其转发的客户端地址的反向代理。环回地址始终受信任。留空时，列表来自 `EVEY_TRUSTED_PROXIES`。 |
| **LAN 网络** | 被视为家庭网络的地址范围。默认包含私有地址范围。如果某个 VPN（Tailscale、WireGuard）的客户端应算作家庭网络，在这里添加它的地址范围。 |
| **最大远程码率** | 对本地网络之外的客户端的码率上限，单位 kbit/s（0 = 无）。私有地址从不受限。当 **Admin → 转码** 也为远程观众设置了上限时，取两者中较低的一个。见[Evey 如何选择播放方式](../playback/how-playback-is-decided.md#limits-on-the-session)。 |

## HTTPS：Evey 前面的反向代理

Evey 在 9091 端口上提供未加密的 HTTP，API 和网页界面在一起。HTTPS 由反向代理负责，它把所有请求转发到 `evey-server:9091`。Evey 需要知道关于它的两件事，都在 **Admin → 远程访问** 中：

- 以 `https://` 开头的**外部 URL**。这告诉 Evey 由代理终止 TLS：Cookie 会带上 `Secure` 标志，会发送 HSTS，并相信来自受信任代理的 `X-Forwarded-Proto` 头。
- **受信任的代理**，当代理与 Evey 不在同一台机器上时。位于另一个容器中的代理需要在这里填写它的网络，例如 Docker 默认网络的 `172.16.0.0/12`。覆盖所有地址的范围（`0.0.0.0/0`、`::/0`）会被拒绝：否则任何客户端都可以选择自己被看到的地址。

如果还没有代理，Evey 仓库中包含一个 Caddy 服务，它会自己获取 Let's Encrypt 证书。适用于 Caddy、Nginx、Traefik 和 Nginx Proxy Manager 的现成配置，以及代理的默认设置对流媒体的影响：[反向代理配置](../reverse-proxy.md)。

### 在环境中设置

`EVEY_SERVER_BASE_URL` 和 `EVEY_TRUSTED_PROXIES` 在 compose 文件中给出同样的答案，适合完全以代码描述的安装，或者从第一次启动起就必须能通过 HTTPS 访问的服务器。两者都设置时以面板为准：`https://` 外部 URL 即使在基础 URL 是未加密 HTTP 时也会开启 HTTPS 模式，而保存的代理列表会取代环境变量。清空字段会把答案交还给环境变量。见[服务器与网络](../environment/server.md)。

## 两个网络步骤

受信任的代理和 LAN 网络是先后两个步骤，而不是同一件事的两种说法。受信任的代理决定相信谁转发的地址，因此决定每个客户端得到什么地址；LAN 网络随后把这个地址归类为本地或远程。

## 客户端的真实地址

远程访问和 **最大远程码率** 都依赖于 Evey 能看到每个客户端的真实地址。一个不转发真实地址、或者不被 Evey 信任的代理，会让每个请求看起来都来自代理的私有地址：所有人都算作家庭网络，远程访问设置不起作用，也不会应用任何远程限制。

因此，修好代理会改变谁算作远程。如果远程访问是关闭的，从那一刻起远程客户端就会被拒绝。更改代理设置后检查 `evey admin doctor`：它会显示当前生效的列表及其来源，对公网地址范围发出警告，并对覆盖所有地址的范围报告失败。
