# एक्सटेंशन API

एक्सटेंशन और webhook एकीकरण के प्रबंधन के endpoints।

## विनिर्देश

| विनिर्देश | विवरण |
|------|-------------|
| [admin_plugin.swagger.json](admin_plugin.swagger.json) | एक्सटेंशन इंस्टॉल, चालू, बंद और अनइंस्टॉल करना। एक्सटेंशन का कॉन्फ़िगरेशन और लॉग। एक्सटेंशन रनटाइम। |
| [webhook.swagger.json](webhook.swagger.json) | webhooks बनाना, पढ़ना, बदलना, हटाना; डिलीवरी इतिहास |

## एक्सटेंशन विकास

एक्सटेंशन gRPC के ज़रिए Evey सर्वर से बात करते हैं। पूरी विकास गाइड के लिए [एक्सटेंशन दस्तावेज़](../../plugins.md) देखें, जिसमें शामिल है:
- एक्सटेंशन का जीवनचक्र (इंस्टॉल, चालू, कॉन्फ़िगर, बंद, अनइंस्टॉल)
- उपलब्ध event hooks
- कॉन्फ़िगरेशन schema
- सुरक्षा सैंडबॉक्सिंग (seccomp, प्रक्रिया अलगाव)
