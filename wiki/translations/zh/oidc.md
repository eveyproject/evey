# OIDC / SSO 设置

Evey 支持通过 OpenID Connect 进行单点登录：Keycloak、Authentik、Authelia、Google 或任何其他 OIDC 提供方。网页和 Android 应用的登录页随后会在密码表单旁显示 **使用 SSO 登录**。

## 1. 在提供方注册 Evey

在提供方创建一个客户端（或应用），授权类型为 Authorization Code，scopes 为 `openid email profile`，生成客户端密钥，并填写 **单点登录 (SSO)** 卡片在 **在提供方处登记以下地址** 下显示的两个地址：

| 字段 | 值 |
|-------|-------|
| 重定向 URI | `https://<你的地址>/api/v1/auth/oidc/callback` |
| 退出后重定向 URI | `https://<你的地址>/login` |

两者都根据服务器的公开地址（**Admin → 远程访问**）生成：如果用户通过其他地址访问 Evey，请先在那里设置。

## 2. 配置 Evey

**Admin → 服务器配置 → 单点登录 (SSO)**：

| 字段 | 作用 |
| --- | --- |
| **启用单点登录** | 在登录界面显示 SSO 按钮。 |
| **颁发者 (Issuer) URL** | 提供方的地址，不含 `/.well-known/openid-configuration`。 |
| **客户端 ID**、**客户端密钥** | 上面注册的客户端。密钥保存在服务器上，之后不再显示；保留圆点即保留当前密钥。 |
| **允许的电子邮件域名** | 逗号分隔。设置后只接受这些地址，并且提供方必须确认该地址。 |
| **按钮文字** | 可选，替换“使用 SSO 登录”。 |
| **通过已验证的电子邮件关联现有账户** | 默认开启。见下文。 |
| **为新的 SSO 用户创建账户** | 除非允许了电子邮件域名，否则关闭。见下文。 |
| **新 SSO 账户的媒体库访问权限** | **所有媒体库**，或 **仅限所选媒体库**。 |

**测试连接** 检查颁发者是否应答。**保存 SSO 设置** 立即生效，无需重启。**状态** 一行显示提供方是否可达，不可达时显示最近的错误。

[账户与登录](environment/accounts.md)中的 `EVEY_OIDC_*` 变量是后备：卡片会提示其值何时来自这些变量，保存卡片后即由卡片接管。

服务器从不等待提供方：即使提供方未运行，服务器也会启动；只要无法连接提供方，SSO 按钮就保持隐藏，密码登录照常可用。下一次登录尝试时会再次联系提供方，最多每 30 秒一次。

## 谁可以登录

1. 已经用该提供方登录过的账户会再次登录，除非已被禁用。
2. 否则，在开启 **通过已验证的电子邮件关联现有账户** 时，电子邮件相同的现有账户会与提供方关联并登录，但前提是提供方确认了该地址。该账户保留原有密码。管理员账户永远不会以这种方式关联。
3. 否则，在开启 **为新的 SSO 用户创建账户** 时，会创建一个新账户，带一个个人资料和卡片中选择的媒体库访问权限。用户名取提供方的 `preferred_username`，否则取电子邮件中 `@` 之前的部分；已被占用的名称会加上一个简短的后缀。

当没有允许任何电子邮件域名时，**为新的 SSO 用户创建账户** 默认关闭：对于 Google 这样的公共提供方，否则任何在那里拥有账户的人都能在你的服务器上获得账户。关闭时，只有现有账户可以通过 SSO 登录。

登录被拒绝时，登录页会说明原因：电子邮件域名不被允许、没有匹配的账户且未开启创建账户、账户已被禁用、账户存在但无法关联，或者提供方不可用。

## 登出

当提供方公布了登出端点时，在 SSO 登录后从 Evey 登出也会结束提供方的会话，然后返回 Evey 的登录页。卡片会显示提供方是否支持。
