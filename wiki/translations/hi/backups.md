# बैकअप

Evey आपके डेटाबेस का बैकअप एक तय समय-सारणी पर अपने आप ले सकता है।

## कॉन्फ़िगरेशन

```env title=".env"
EVEY_BACKUP_DIR=/data/backups          # बैकअप यहाँ रखे जाते हैं
EVEY_BACKUP_INTERVAL_HOURS=24          # स्वतः बैकअप का अंतराल (0 = बंद)
EVEY_BACKUP_RETENTION_DAYS=30          # इससे पुराने बैकअप हटा दें (0 = हमेशा रखें)
```

## बैकअप में क्या आता है

बैकअप में उपयोगकर्ता का सारा डेटा शामिल रहता है:
- उपयोगकर्ता, प्रोफ़ाइल, भूमिकाएँ, अनुमतियाँ
- लाइब्रेरी, संग्रह, प्लेलिस्ट, पसंदीदा
- देखे जाने की स्थिति, प्लेबैक इतिहास
- एक्सटेंशन, सर्वर कॉन्फ़िगरेशन, निर्धारित कार्य
- सूचनाएँ, webhooks, ऑडिट लॉग

**बैकअप में शामिल नहीं**: मीडिया फ़ाइलें (वे आपकी अपनी हैं) और ट्रांसकोडिंग कैश (यह अपने आप दोबारा बन जाता है)।

## बैकअप का प्रारूप

हर बैकअप एक `.tar.gz` फ़ाइल होती है, जिसमें ये रहते हैं:
- `manifest.json` - मेटाडेटा, संस्करण, SHA256 अखंडता हैश
- `dump.sql` - पूरा PostgreSQL डंप

## बैकअप खुद लेना

बैकअप आप व्यवस्थापन पैनल से ले सकते हैं, या API के ज़रिए:

```bash
curl -X POST -H "Authorization: Bearer <token>" http://localhost:9091/api/v1/admin/backups
```

## पुनर्स्थापना

बैकअप से पुनर्स्थापना व्यवस्थापन API के ज़रिए होती है। लागू करने से पहले बैकअप की अखंडता SHA256 हैश से जाँच ली जाती है।

## स्थायी भंडारण

ध्यान रखें कि `EVEY_BACKUP_DIR` किसी स्थायी वॉल्यूम या होस्ट के पथ पर जाता हो। डिफ़ॉल्ट `/data/backups`, `evey-data` नाम के Docker वॉल्यूम के भीतर ही रहता है।

बैकअप होस्ट पर रखने के लिए:
```yaml title="docker-compose.yml"
services:
  evey:
    volumes:
      - /path/on/host/backups:/data/backups
```
