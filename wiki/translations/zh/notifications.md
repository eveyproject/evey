# 通知

当有新的电影、剧集、季、单集或专辑到来时，Evey 会通知每个个人资料。管理员还会收到备份失败、插件错误和新媒体请求的通知，提出请求的人会在请求得到答复时收到通知。

## 通知出现在哪里

- **每个应用中**：铃铛图标，带未读数量。始终开启，无需设置。通知保留 30 天。列表只显示该账户可以打开的媒体库中的标题。
- **浏览器推送**：在网页上，每个个人资料在 **设置 → 通知** 中开启 **推送通知**，每个浏览器开启一次。服务器在首次启动时创建推送密钥；如需使用自己的密钥，见[电子邮件与通知](environment/notifications.md#browser-push)。浏览器只在 HTTPS 地址（或 `localhost`）上允许推送；其他情况下该设置会显示 **推送通知需要 HTTPS 地址：请通过 HTTPS 打开此服务器以启用推送通知。** Android 和电视应用不接收推送通知。
- **电子邮件**：配置电子邮件后，每条通知也会发送到账户的邮箱地址，使用该个人资料的语言，并附有服务器链接。拥有多个个人资料的账户每个事件只收到一封邮件。没有按用户退订的选项。

## 设置电子邮件

**Admin → 服务器配置 → 邮件 / SMTP**：邮件服务器、端口、登录账户、发件人地址和 TLS 模式。保存后立即生效，无需重启。**发送测试邮件** 会用已保存的设置向你自己账户的邮箱发送一封简短邮件，失败时显示邮件服务器的应答。

`starttls` 将明文连接升级为 TLS（通常为 587 端口），`ssl` 从一开始就使用 TLS（通常为 465 端口），`none` 不加密发送。

只要卡片中没有填写主机，就使用 `EVEY_SMTP_*` 变量作为后备：

```env title=".env"
EVEY_SMTP_HOST=smtp.example.com
EVEY_SMTP_PORT=587
EVEY_SMTP_USERNAME=notifications@example.com
EVEY_SMTP_PASSWORD=your-smtp-password
EVEY_SMTP_FROM=noreply@example.com
EVEY_SMTP_TLS=starttls
```

一旦在卡片中保存了主机，所有字段都取自卡片，变量将被忽略：因此服务器绝不会把变量中的凭据发送给面板中填写的邮件服务器。

电子邮件用于通知和密码重置；邀请是你自己分享的链接。

## 每个个人资料收到什么

在 **设置 → 通知** 中，每个个人资料为 **电影**、**剧集** 和 **音乐** 各选择一个级别：

| 级别 | 通知的新标题 |
| --- | --- |
| **全部** | 每一个。默认值。 |
| **相关** | 只通知与该个人资料常看类型有共同类型的标题。 |
| **仅重要** | 目前与相关相同。 |
| **已禁用** | 不通知。 |

某个类型在该个人资料最近 200 次播放中至少出现 3 次时，才算作常看类型。没有类型的标题在相关和仅重要级别下永远不会被通知。

同一部剧集在 24 小时内到来的多集只产生一条通知并计数；如果该剧集或该季刚刚通知过，则不再发送。

## 密码找回

1. 设置电子邮件（见上文）。
2. 在 **Admin → 服务器配置 → 服务器设置** 中开启 **密码找回**。立即生效。
3. 登录页随后会显示 **忘记密码？**，通过电子邮件发送重置链接。

没有 SMTP 时，即使开启了该选项，链接也会保持隐藏。
