# लाइब्रेरी और मेटाडेटा

स्कैनिंग, मेटाडेटा स्रोत और इंट्रो पहचान। इनमें से ज़्यादातर का एडमिन पैनल में एक समकक्ष है, जो वहाँ मान सहेजे जाने के बाद भारी पड़ता है।

## स्कैनिंग

| वेरिएबल | डिफ़ॉल्ट | असर |
| --- | --- | --- |
| `EVEY_LIBRARY_WATCHER_ENABLED` | `true` | रीयल-टाइम फ़ाइल निगरानी। |
| `EVEY_LIBRARY_PERIODIC_SCAN_INTERVAL` | `2m` | वॉचर से छूटी चीज़ों के लिए फ़ोल्डर कितनी बार जाँचे जाते हैं (नेटवर्क शेयर)। **Admin → सर्वर कॉन्फ़िग → सर्वर सेटिंग्स** इसे ओवरराइड करता है। |
| `EVEY_LIBRARY_SCAN_WORKERS` | CPU हिस्से से | स्कैन के दौरान समानांतर विश्लेषित फ़ाइलें। हाथ से सेट करने पर स्कैन के लिए **आवंटित प्रोसेसिंग क्षमता** हिस्सा छोड़ दिया जाता है। |
| `EVEY_SEEKINDEX_STATE_DIR` | `/data/seek-index` | मीडिया स्वास्थ्य स्कैन अपने नतीजे और चल रहा काम रीस्टार्ट के बीच कहाँ रखता है। ख़ाली: नहीं रखा जाता। |

## मेटाडेटा

| वेरिएबल | डिफ़ॉल्ट | असर |
| --- | --- | --- |
| `EVEY_METADATA_LANGUAGE` | `en` | टाइटल और सारांश की भाषा। सेटअप विज़ार्ड में या **Admin → सर्वर कॉन्फ़िग → भाषा और क्षेत्र** में चुनी गई भाषा भारी पड़ती है। |
| `EVEY_TMDB_API_KEY` | शामिल कुंजी | आपकी अपनी TMDB कुंजी, आपके अपने कोटे के लिए। **Admin → सर्वर कॉन्फ़िग → API कुंजियाँ** में सेट की गई कुंजी भारी पड़ती है। |
| `EVEY_OMDB_API_KEY` | ख़ाली | एक OMDb कुंजी, फ़िल्मों के लिए दूसरा स्रोत। वही ओवरराइड। |
| `EVEY_OPENSUBTITLES_API_KEY` | ख़ाली | एक OpenSubtitles कुंजी, API के ज़रिए सबटाइटल खोजने के लिए। वही ओवरराइड। |
| `EVEY_OPENSUBTITLES_USERNAME`, `EVEY_OPENSUBTITLES_PASSWORD` | ख़ाली | एक OpenSubtitles खाता, उसकी API में साइन इन करने के लिए। |

## इंट्रो, रीकैप और क्रेडिट

| वेरिएबल | डिफ़ॉल्ट | असर |
| --- | --- | --- |
| `EVEY_INTRO_PROVIDERS_ENABLED` | `false` | सर्वर की अपनी पहचान से पहले सामुदायिक डेटाबेस (TheIntroDB, फिर IntroDB) इस्तेमाल करता है। **Admin → सर्वर कॉन्फ़िग → इंट्रो स्किप प्रदाता** भारी पड़ता है; बदलने के बाद रीस्टार्ट करें। |
| `EVEY_INTRO_TIDB_API_KEY` | ख़ाली | एक TheIntroDB कुंजी: 100 की बजाय रोज़ 500 खोजें। |
| `EVEY_INTRO_AUTO_SKIP_ENABLED` | `false` | हर प्लेयर पहचाने गए इंट्रो अपने आप छोड़ता है। पैनल से तुरंत लागू होता है। |
| `EVEY_INTRO_SKIP_PREVIEW_ENABLED` | `false` | अगले एपिसोड का पूर्वावलोकन छोड़ने का विकल्प भी देता है। पैनल से तुरंत लागू होता है। |
| `EVEY_INTRO_DETECTION_MAX_PARALLEL` | CPU हिस्से से | एक साथ विश्लेषित टाइटल। हाथ से सेट करने पर इस काम के लिए **आवंटित प्रोसेसिंग क्षमता** हिस्सा छोड़ दिया जाता है। |
| `EVEY_INTRO_FFMPEG_THREADS` | `1` | पहचान के दौरान हर ffmpeg प्रोसेस के थ्रेड (1 से 16)। |
