# 观众设置

每个账户无需找管理员就能自己修改的内容。大部分在**设置**里（头像菜单，然后是设置）；其余
在播放器中。Android 和电视应用在各自的设置页面里提供相同的设置。

设置跟随屏幕前的**个人资料**，而不是设备：在电视上选了英语音轨，手机也会用英语音轨。

## 外观与语言

| 设置 | 作用 |
| --- | --- |
| **主题** | 配色主题，包括管理员安装的主题。 |
| **语言** | 界面语言。共有六种：英语、法语、德语、西班牙语、印地语和中文。 |
| **区域** | 显示和执行哪个国家的年龄分级。**自动**跟随服务器。 |
| **首选音频语言** | 文件有多种语言时优先选择的音轨。 |
| **首选字幕语言** | 有匹配时显示的字幕轨；**无偏好**则默认不开字幕，除非文件强制显示。 |

标题和简介使用服务器的元数据语言，由管理员选择。

## 播放

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| **自动播放下一集** | 开 | 一集结束后开始下一集。"下一集"按钮无论如何都在。 |
| **最大流媒体比特率** | 不限 | 你的流的上限。网络慢时调低它：服务器会转码以适应上限，而不是让播放器卡住。 |
| **最大蜂窝数据比特率**（手机） | - | 只在移动数据下生效的更低上限。 |
| **首选视频编码** / **首选音频编码** | 自动 | 保持自动，除非某台设备在某种编码上出问题：自动让服务器选择设备解码效果最好的编码。 |
| **最大音频声道** | 自动 | 立体声、5.1 或 7.1。如果你用耳机或电视扬声器观看，觉得环绕声混音里的对白太小，就选立体声。 |
| **字幕内嵌** | 自动 | 某些字幕格式（图形字幕，或样式很重的字幕）不是每个播放器都能绘制；自动只在这种情况下把字幕烧进画面。**始终内嵌**和**从不内嵌**会强制执行，代价是一次转码或字幕缺失。 |
| **允许直接播放** / **直接流** / **转码** | 全部开启 | 电影到达你的三种方式：原样、重新封装或转码。关掉其中一种是排查问题的工具，而不是日常设置。 |

管理员可以为你的账户或来自家外的连接设置更低的上限；始终以最低的上限为准。

## 在播放器中

齿轮图标打开播放器设置：

- **画质**：**自动**随你的网络调整；**原画质**在设备能读取时请求未经改动的文件；固定高度
  （1080p、720p……）会强制按该尺寸转码。
- **音频**和**字幕**：随时切换音轨，不必从头开始。**上传字幕…**为这个标题从你的电脑添加
  一个字幕文件。
- **音频同步**：以毫秒为单位移动声音相对画面的时间（正值 = 声音延后）。仅在转码播放时可用；
  应用后会从当前位置重新开始播放。
- **字幕同步**：移动字幕时间（正值 = 延后），立即生效。
- **字幕样式**：大小、文字颜色、背景、字体、位置、阴影。
- **速度**和**睡眠定时器**（若干分钟，或到本集结束）。

进度条周围：**章节**；服务器知道位置时会出现**跳过片头**、**跳过前情提要**和**跳过片尾**
按钮；下一集倒计时；**投屏**、**播放到**（发送到另一个 Evey 应用）、**一起看**和**下载**
（手机）。

**流信息**告诉你电影是如何送到你这里的 - 直接播放、remux 还是转码 - 以及原因。播放出问题时，
首先要看的就是它："此播放器无法解码的音频编码"或"码率超出允许上限"通常就能说明原因。

在电脑上，按 `?` 显示键盘快捷键：`空格`或 `K` 暂停，`J`/`L` 或左右方向键跳转，上下方向键
调音量，`F` 全屏，`M` 静音，`C` 字幕，`<` 和 `>` 调速度，`P` 画中画，`0` 到 `9` 跳到影片
的 0-90 % 处。

## 个人资料与家长控制

**设置 > 个人资料**用于创建、编辑和删除个人资料（默认个人资料不能删除）。每个个人资料包含：

| 字段 | 作用 |
| --- | --- |
| **名称**和**头像** | 显示在"谁在观看？"页面上。 |
| **儿童个人资料** | 打开时不需要 PIN；离开它切换到其他个人资料时需要账户 PIN。 |
| **最大年龄分级** | 高于此分级的标题永远不会发给这个个人资料 - 不出现在列表里、搜索里，也不会发给播放器。由服务器决定：任何应用都无法绕过。 |
| **语言**和**区域** | 为这个个人资料覆盖界面语言和分级所属国家。 |

**设置 > 家长控制**设置账户的 **4 位 PIN**。第一次设置时需要输入账户密码；之后修改需要当前
PIN。只要存在儿童个人资料，PIN 就是必需的。

如果服务器读不出某个个人资料的年龄设置，它宁可什么都不显示，也不会全部显示：一个损坏的
设置绝不会向孩子打开整个媒体库。

## 下载（手机）

在电影、季、剧集、合集或播放列表上点**下载**即可存到手机。电影太大、剩余空间放不下时，应用
会提供一个由服务器准备的较小副本，并显示每个选项的预计大小。**下载**页列出已存储的内容及其
占用空间。

下载内容仍受个人资料规则约束：超出某个个人资料年龄限制的标题，即使是其他个人资料下载的，
在该个人资料下也无法播放。徽章会提示下载何时已过期、需要重新获取。

## 通知

**设置 > 通知**为这台设备开启推送通知，并分别为电影、剧集和音乐设置你想接收的程度：
**全部**、**相关**、**仅重要**或**已禁用**。推送需要管理员事先配置好
（[通知](../notifications.md)）。

## 账户与设备

- **账户**（个人资料卡片）：用户名、邮箱、密码（至少八个字符）和头像。忘记密码时正是靠
  邮箱来重置，前提是服务器能发送邮件。
- **设备**：已注册推送通知的设备，可以移除。
- **快速连接**：输入或扫描电视或其他设备上显示的代码，把它连接到你的账户，而不必在上面
  输入密码。
- **观看历史**（个人资料菜单）：你看过的所有内容，按天排列，可以删除单条或全部清空。
- **插件**：如果管理员安装了带有自身偏好设置的扩展，它们会出现在这里。

## 请求

如果管理员允许，**媒体请求**可以让你搜索媒体库里没有的电影、剧集或艺术家并提出请求。
**我的请求**显示处理结果：已同意、已拒绝或稍后，并附有管理员的备注。
