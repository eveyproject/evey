# 首次设置

服务器已经在运行，你也打开了 `http://<server-address>:9091`。在大家可以观看之前还剩四步：设置向导、媒体库、用户和应用。

## 1. 设置向导

还没有管理员的服务器会打开一个四步的向导：

1. **语言**：新个人资料和元数据（标题、简介、类型）的默认语言。
2. **欢迎**。
3. **管理员账户**：至少 3 个字符的用户名和至少 8 个字符的密码。可选的服务器名称会显示在登录页面和应用的服务器列表中。
4. **第一个媒体库**：一个名称和一个类型。可以跳过，之后再添加媒体库。

## 2. 添加媒体库

**Admin → 媒体库 → 添加媒体库**：一个名称、一个类型（电影、电视剧、音乐或照片）以及一个或多个文件夹。

这些文件夹是**容器内**的路径。使用安装页面的 compose 文件时，你的媒体文件夹是 `/media`：主机上位于 `/srv/media/films` 的电影文件夹，对 Evey 来说是 `/media/films`。

第一次扫描会自动开始。新文件出现时会被发现，海报、简介和演员表在后台陆续到来，所以一个大型媒体库会在几分钟内逐渐填满。

文件应该如何命名、扫描如何工作、如何纠正错误的匹配：[媒体库与元数据](../administration/libraries.md)。

## 3. 添加使用者

**Admin → 用户** 可以创建一个由你设定密码的账户，或者生成一个邀请链接，让对方自己设置密码。之后每个账户创建自己的个人资料：家里每人一个，包括儿童个人资料。

管理员可以按账户限制什么，以及个人资料和家长控制如何工作：[用户、个人资料与家长控制](../administration/users.md)。

## 4. 连接应用

网页应用就是你已经打开的地址。Android 和 Android TV 应用会先询问服务器地址，然后登录；电视可以用一个在手机上批准的代码登录。见[应用与设备](apps.md)。

## 服务器自己完成的事情

以下这些都不需要设置：

- **播放。** 每台设备报告它能解码什么，服务器逐个条目地选择：原样发送文件、重新封装，或者只重新编码设备无法播放的部分。见[Evey 如何选择播放方式](../playback/how-playback-is-decided.md)。
- **容量。** 在第一个空闲时刻，服务器会测量它能同时转码多少个视频，包括使用处理器和映射进容器的任何显卡，并且绝不接受超过这个数量。测量需要几分钟；在此期间需要转码的播放会被要求稍候。见[转码与服务器容量](../playback/transcoding.md)。
- **远程访问。** 服务器获得公网地址时开启，否则保持关闭。见[远程访问与 HTTPS](../administration/remote-access.md)。
- **备份。** 每次会改变数据库的更新之前，都会先导出数据库。定期计划只需一个设置：[备份与更新](../backups.md)。

## 在把地址分享到家庭之外之前

1. 把服务器放在 HTTPS 之后：Evey 提供的是未加密的 HTTP。[远程访问与 HTTPS](../administration/remote-access.md)。
2. 设置备份计划，并保留一份 `./evey-data` 的副本：其中有数据库和签署每个会话的密钥。[备份与更新](../backups.md)。
