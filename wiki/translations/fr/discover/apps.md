# Sur tous les écrans

Un serveur, une bibliothèque, les mêmes points de reprise partout. Chaque
application parle à votre propre serveur : vous tapez son adresse une fois,
vous vous connectez, vous choisissez un profil, et vous êtes chez vous.

## Dans un navigateur

L'application web est servie par le serveur lui-même, à l'adresse que vous
ouvrez après l'installation : rien à installer sur l'ordinateur. Elle offre
toute l'expérience - films, séries, musique, photos, Regarder ensemble - plus
le panneau d'administration pour les administrateurs. Sur un ordinateur, le
lecteur répond au clavier (appuyez sur `?` pour voir les raccourcis).

## Sur un téléphone ou une tablette Android

L'application Android ajoute ce qu'un téléphone fait bien :

- les **téléchargements** pour regarder hors ligne, avec une copie plus légère
  préparée par le serveur quand l'original ne tiendrait pas ;
- le **cast** vers un Chromecast depuis le lecteur ;
- le **scan d'un code de connexion rapide** pour connecter une télévision sans
  taper de mot de passe à la télécommande ;
- les **notifications push** quand de nouveaux films, épisodes ou morceaux
  arrivent, au niveau que vous choisissez pour chacun, si le serveur est
  configuré pour cela.

## Sur Android TV

L'application TV est pensée pour la télécommande : de grandes affiches, des
rangées que l'on parcourt avec les flèches, un lecteur dont les commandes se
font discrètes. La connexion ne demande pas de taper un mot de passe : la
télévision affiche un code de **connexion rapide** (et un QR code), vous
l'approuvez depuis un téléphone ou un ordinateur déjà connecté, et la télé est
prête.

## Sur un Chromecast

Depuis le lecteur web dans Chrome, ou depuis l'application Android, le bouton
**Caster** envoie le film vers un Chromecast ou une télévision avec Chromecast
intégré. Le serveur le pilote directement avec son propre récepteur : ce qui
est lu sur la télé est choisi pour la télé - ses codecs, son écran, sa
connexion - et non pour le téléphone qui l'a envoyé.

## D'une application Evey à l'autre

**Lire sur** envoie ce que vous regardez vers une autre application Evey
ouverte sur le même compte - l'application TV du salon, le téléphone posé sur
le bureau - et la lecture démarre là-bas. Le bouton liste les appareils en
ligne à cet instant.

## Lequel lit le mieux ?

Le serveur vérifie ce que chaque appareil sait décoder et s'adapte : le même
film peut être envoyé intact à la télé et converti pour un vieux téléphone.
Vous pouvez voir la décision, et ses raisons, dans le panneau **Infos du flux**
du lecteur.
