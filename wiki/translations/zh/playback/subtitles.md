# 字幕

字幕会怎样处理取决于它的格式：文本，还是图像。

| 格式 | 示例 | 如何显示 | 对视频的影响 |
| --- | --- | --- | --- |
| 文本 | SRT、ASS/SSA、WebVTT、文件内的字幕 | 与视频一起发送，由播放器绘制 | 无 |
| PGS（蓝光） | `hdmv_pgs_subtitle` | 由服务器一次性解码为图像并缓存，由播放器绘制 | 无 |
| 其他图像格式 | VobSub（DVD）、DVB、XSUB | 由服务器烧录进画面 | 视频被重新编码 |

所有播放器（网页、Android、Android TV）都自己绘制文本和 PGS 字幕，所以选择其中之一永远不会改变视频的传送方式。只有最后一行会：把字幕烧录进画面需要解码并重新编码视频，所以一个原本直接播放的条目会变成转码。此时流信息会列出 **字幕已烧录进画面**。

图像字幕只有在你真正选择它时才会被烧录。一个只是带有图像字幕、或者把它标记为默认的文件，仍然保持直接播放。

## 字幕内嵌

个人资料设置 **字幕内嵌**（**设置 → 播放**）决定最后一行中的格式：

- **自动** 和 **始终内嵌**：选中的 VobSub、DVB 或 XSUB 轨道会被烧录。无论如何设置，文本字幕都不会被烧录。
- **从不内嵌**：视频从不因字幕而重新编码。此时 VobSub、DVB 或 XSUB 轨道无法显示。

## 选择与调整

- 播放器会选择个人资料的 **默认字幕语言** 对应的字幕，其次是文件标记为默认的轨道（例如强制字幕轨道）。
- 播放器中的 **字幕同步** 会为当前条目平移字幕（正值让字幕更晚显示）。立即生效。
- **字幕样式** 设置文本字幕的大小、颜色、背景、字体和位置。
- **上传字幕…** 为该条目添加一个文件。
- 有了 OpenSubtitles 密钥（见[媒体库与元数据](../administration/libraries.md#metadata-keys)），服务器 API 可以搜索并下载文件中没有的字幕（`GET /api/v1/media/{id}/subtitles/search`，然后 `POST /api/v1/media/{id}/subtitles/download`）。文件会保存在电影旁边的 `.subtitles` 文件夹中。
  应用暂时还不提供这个搜索功能。
