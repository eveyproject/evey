# 用户、个人资料与家长控制

## 账户与个人资料

**账户**用于登录：它有一个用户名和密码（或单点登录身份，见 [OIDC](../oidc.md)），并且要么是管理员，要么不是。**个人资料**用于观看：每个账户有一个或多个个人资料，每个都有自己的观看记录、继续播放位置、收藏、语言和首页。一个家庭通常共用一个账户，每人一个个人资料。

## 创建账户

**Admin → 用户** 提供两种方式：

  ![演示服务器上的 Admin → 用户](../images/admin-users.webp){ loading=lazy }
  <figcaption><strong>Admin → 用户</strong>：每个账户及其个人资料、角色和状态（界面为英文）。</figcaption>
</figure>

- **创建用户**：由你选择用户名和密码。
- **创建邀请链接**：由对方自己选择。链接可以设置过期日期和最大使用次数，限制新账户能看到的媒体库，限制它可以创建的个人资料数量，还可以创建管理员。**邀请链接** 会列出所有链接；链接可以被撤销。

## 管理员可以按账户限制什么

| 设置 | 效果 |
| --- | --- |
| **媒体库访问** | 账户能看到的媒体库。其余内容不会出现在它的搜索、首页和 API 响应中。 |
| **最大码率** | 账户的播放器所接收码率的上限（0 = 不限）。高于它的条目会被转码到这个上限以下。 |
| **最大配置文件数** | 账户可以创建多少个个人资料（0 = 不限）。 |
| **每个配置文件的最大设备数** | 每个个人资料在其所有设备上可同时进行多少个播放（0 = 不限）。超出时，新的播放在开始时会被拒绝。 |

**以此身份登录** 会以该用户看到的样子打开服务器，用于检查某项限制或重现问题。期间会一直显示一条横幅，**退出** 会回到你自己的账户。

## 儿童个人资料与 PIN 码

标记为**儿童个人资料**的个人资料无需 PIN 码即可打开。从它切换到非儿童个人资料时，会要求输入在 **设置 → 家长控制** 中设置的 **4 位数字 PIN 码**。首次设置 PIN 码时需要输入账户密码，并且只要存在儿童个人资料，账户就必须有 PIN 码。

只有在非儿童个人资料中，才能管理个人资料和家长控制设置。

## 年龄限制

每个个人资料都可以设置一个**最大年龄分级**（**设置 → 个人资料 → 编辑**）。分级制度采用 **Admin → 服务器配置 → 语言和地区** 中所设国家的制度。

这个限制由服务器执行，而不是由应用执行：高于限制的条目不是在界面中被隐藏，而是从不发送。浏览和搜索、播放以及下载都是如此。如果服务器无法读取某个个人资料的设置（例如数据库出错），它会拒绝内容而不是放行。管理员不受个人资料限制的约束。

下载到手机的电影在离线时仍受限制：儿童个人资料无法打开由另一个个人资料下载的、超出其年龄限制的内容。

## 请求

用户可以搜索媒体库中没有的电影、剧集或艺术家并提出请求。请求会进入 **Admin → 媒体请求**，管理员可以在那里批准、拒绝或推迟，并附上备注。谁可以提出请求也在那里设置：默认所有人都可以，并可按用户设置例外。

## 公开下载链接

在电影或剧集的页面上，管理员可以创建一个 **公开下载链接**（网页和 Android 应用）。这是一个任何人无需账户即可打开、用来下载原始文件的地址；它会被复制到剪贴板。

- 它在 48 小时后过期。通过服务器 API，它最长可以持续 72 小时，并可以限制下载次数（`POST /api/v1/media/{id}/share`）。
- 只有管理员可以创建、列出和撤销链接。应用只能创建链接：列出和撤销要通过 API 完成（`GET /api/v1/admin/share-links`、`DELETE /api/v1/share-links/{id}`）。
- 远程访问关闭时，链接只能从本地网络使用。
- 持有链接的人在其过期之前都可以下载该文件：请像对待文件本身一样分享它。

## 主页

主页由一行行内容堆叠而成；没有内容可显示的行会被隐藏。

| 行 | 显示内容 |
| --- | --- |
| **继续播放** | 该个人资料已开始但尚未看完的内容，最近的在前。一个标题在看到 90% 时算作已观看。 |
| **即将播放** | 对于该个人资料看过其中一集的每部剧集，显示下一集未看的剧集。 |
| **合集** | 各个合集，并附有完整列表的链接。 |
| **为您推荐** | 属于该个人资料常看类型的电影和剧集，最匹配的在前，然后按评分排序。某个类型在该个人资料最近 200 次播放中至少出现 3 次时才算数。 |
| **最受欢迎** | 过去 90 天内在服务器上播放次数最多的电影和剧集。 |
| 每个媒体库一行 | 该媒体库最新添加的内容，最新的在前。 |

为您推荐和最受欢迎会排除该个人资料已经看完的内容；一部剧集在每一集都看过后才算看完。插件可以添加自己的行。

**Admin → 服务器配置 → 主页信息流** 为所有个人资料设定默认值：显示哪些行、以什么顺序、每行显示多少项。之后每个个人资料可以用 **自定义** 安排自己的主页（在网页和移动应用的主页上，在电视应用的顶栏中）：显示或隐藏某一行、移动它，或 **恢复默认**。该选择保存在服务器上，并随个人资料出现在每台设备上。个人资料可以显示管理员隐藏的行，但插件的行除外：在那里管理员的选择是最终的。
