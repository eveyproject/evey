# प्लगइन API

प्लगइन और वेबहुक एकीकरण प्रबंधित करने के एंडपॉइंट।

## विनिर्देश

| विनिर्देश | विवरण |
|------|-------------|
| [admin_plugin.swagger.json](admin_plugin.swagger.json) | प्लगइन इंस्टॉल, सक्षम, अक्षम, अनइंस्टॉल करना। प्लगइन कॉन्फ़िग और लॉग। प्लगइन रनटाइम। |
| [webhook.swagger.json](webhook.swagger.json) | वेबहुक CRUD, डिलीवरी इतिहास |
| [plugin_prefs.swagger.json](plugin_prefs.swagger.json) | किसी प्लगइन इंटरफ़ेस की हर उपयोगकर्ता की पसंदें (`prefs` अनुमति) |

## प्लगइन डेवलपमेंट

प्लगइन gRPC के ज़रिए Evey सर्वर से संवाद करते हैं। पूरी डेवलपमेंट मार्गदर्शिका के लिए [प्लगइन दस्तावेज़ीकरण](../../plugins.md) देखें, जिसमें शामिल है:
- प्लगइन जीवनचक्र (इंस्टॉल, सक्षम, कॉन्फ़िगर, अक्षम, अनइंस्टॉल)
- उपलब्ध इवेंट हुक
- कॉन्फ़िगरेशन स्कीमा
- सुरक्षा सैंडबॉक्सिंग (seccomp, प्रोसेस अलगाव)
