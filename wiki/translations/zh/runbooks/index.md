# 运维

服务器已经跑起来之后该做什么：它闹脾气的那天、你要搬走它的那天，
以及你需要把它救回来的那天。

这里的页面默认你有一个终端和一个管理员账号。下面几乎每一件事在管理面板里也做得到；
命令行是面板自己罢工时的后路。

| 你要做的事 | 请读 |
| --- | --- |
| 在服务器上执行一条维护命令 | [命令行](cli.md) |
| 查清某个文件为什么跳转不了，或者播放不同步 | [媒体健康](media-health.md) |
| 把起不来的服务器救回来 | [恢复](recovery.md) |
| 规划或撤销一次数据库迁移 | [迁移](migration-runbook.md) |
| 处理一起正在发生的故障 | [故障处理](incident-runbook.md) |

## 要在出事之前做，而不是出事之后

有两件事值得趁着还没起火的时候确认，因为它们都属于临阵才发现就来不及的那种：
[备份](../backups.md)是不是真的写在了你以为的地方，以及你能不能真的恢复一份。
没有人恢复过的备份，只是一个假设。
