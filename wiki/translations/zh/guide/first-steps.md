# 第一步

容器已经在运行，你也打开了 `http://<你的-ip>:9091`。本页带你走过最初的十分钟：安装向导、
媒体库、成员，以及把地址告诉别人之前值得检查的三件事。如果服务器还没跑起来，请先看
[安装](../installation.md)。

## 安装向导

没有管理员的服务器会打开一个四步向导。

1. **语言。** 新个人资料和元数据（标题、简介、类型）的默认语言。以后可以在
   **管理 > 服务器配置 > 语言和地区**里修改，同时还能设置决定适用哪套年龄分级的地区。
2. **欢迎。**
3. **管理员账户。** 用户名至少三个字符，密码至少八个字符。可选的**服务器名称**（比如
   "客厅"）会显示在登录页、应用的服务器列表和邮件里。
4. **第一个媒体库。** 一个名称和一个类型。细节可以先跳过，之后在管理面板里补完。

## 添加媒体库

**管理 > 媒体库 > 添加媒体库。** 一个媒体库有名称、类型（电影、剧集、音乐或照片）以及
一个或多个文件夹。

**这些文件夹是容器内部的路径**，而不是你主机上的路径。使用默认的 compose 文件时，你的媒体
文件夹挂载在 `/media`：主机上 `/srv/media/films` 里的电影库，对 Evey 来说就是
`/media/films`。第二个挂载的文件夹（`/media2`……）也照此添加。选择器会列出它能看到的文件夹。

请把电影和剧集放在不同的媒体库里：类型告诉扫描器该找什么。Evey 能识别这样的名称：

```text
/media/films/The Mirror (1999)/The Mirror (1999) 1080p.mkv
/media/films/Lantern.2010.1080p.BluRay.x264.mkv
/media/series/The Outpost/Season 01/The.Outpost.S01E05.720p.mkv
/media/series/Quiet Storm/Quiet.Storm.03x10.mkv
```

对电影来说，年份很有帮助。对剧集来说，关键是 `S01E05` 或 `1x05`。发布标签（分辨率、来源、
编码、音频、`VOSTFR` 或 `MULTI` 这类语言标记、"Director's Cut" 这类版本名）会在搜索前被
去掉。如果你的文件带有扫描器不认识的标签，请在**管理 > 服务器配置 > 解析器标记**里添加。

每个媒体库还可以设置：

| 选项 | 作用 |
| --- | --- |
| **实时监控** | 新增、重命名和删除的文件一出现就会被发现。定期检查（默认每 2 分钟一次）会补上文件系统没有通知到的变化，比如网络共享上的。 |
| **启动时扫描** | 每次服务器启动时重新扫描该媒体库。 |
| **计划** | 每 6 或 12 小时、每天、每周，或按你自己的 cron 表达式做一次完整扫描。 |

第一次扫描会自动开始。海报和信息在后台陆续到来，所以大型媒体库几分钟内会逐步填满。

**标题错了或缺失时。** 在媒体库列表里，**仅匹配孤立项**会重试从未被识别的标题，**从 TMDB
重新匹配全部**会对每个标题重新搜索（较慢，但能在大批量重命名后纠正旧的错误）。在单个标题
上，**编辑元数据**可以修正标题，或粘贴正确的 TMDB 或 IMDb 编号。

## 元数据来源

Evey 自带一个 **TMDB** 密钥（标题、海报、演员和合集的来源），所以元数据开箱即用。其他来源
是可选的，它们的密钥在**管理 > 服务器配置 > API 密钥**里填写：

| 密钥 | 带来 |
| --- | --- |
| TMDB（你自己的） | 你自己的配额，而不是共享配额。 |
| OMDb | 第二个元数据来源，用于补全 TMDB 了解不多的标题。 |
| OpenSubtitles | 搜索并下载文件里没有的字幕。 |
| TheIntroDB | 更多片头、前情提要和片尾的时间点（每天 500 次查询，而不是 100 次）。 |

在面板里填写的密钥优先于环境变量中的同一密钥。

## 邀请家人

**管理 > 用户**提供两种方式：

- **创建用户**：用户名和密码由你来定。
- **创建邀请链接**：对方自己设定。链接可以设置过期时间、限制使用次数、只开放部分媒体库、
  限制新账户能创建的个人资料数量，甚至可以创建管理员。

之后你还可以为每个用户限制能看到的**媒体库**，限制其**流媒体码率**、**个人资料**数量和
**每个个人资料的设备**数量，查看其历史，或者**以此身份登录**，准确地看到对方看到的内容。

个人资料、儿童个人资料和家长 PIN 由每个账户自己管理：参见
[观众设置](viewer-settings.md#profiles-and-parental-control)。

## 让服务器测量自己

在一台机器上首次启动时，以及每次硬件变化后，Evey 会测量自己能同时转码多少个视频 - 用处理器，
有显卡的话也用显卡。这大约需要两分钟，只在没人观看时运行；在此期间请求转码的播放器会被告知
稍后再试。结果在**管理 > 转码**里：这个数字是一个上限，你只能调低，不能调高。要使用显卡，
请参见[转码与硬件](../transcoding.md)。

## 分享地址之前

1. **远程访问。** 只有你给了 Evey 一个公网地址，它才会对互联网开放。检查**管理 > 远程访问**：
   如果服务器能从外部访问、但远程访问是关闭的，页面会用红色提示，而你网络之外的所有人都会
   收到错误。参见[管理](admin-settings.md#remote-access)。
2. **HTTPS。** Evey 只提供普通 HTTP。发布之前请把它放在反向代理后面：
   [反向代理](../reverse-proxy.md)。
3. **备份。** 服务器在每次更新前都会备份数据库。若要定期备份，请设置计划：
   [备份](../backups.md)。保管好 `./evey-data` - 里面有数据库和为每个会话签名的密钥。

## 安装应用

打开 Android 或 Android TV 应用，输入服务器地址并登录。在电视上请选择**快速连接**：电视会
显示一个代码和一个二维码，你在一台已登录的手机或电脑上通过**设置 > 快速连接**确认即可。
更多内容见[每一块屏幕](../discover/apps.md)。
