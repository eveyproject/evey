# 常见问题

这里是大家常向家里运行 Evey 的那个人提出的问题，以及简短的回答。每个回答先说该怎么做，再链接到解释原因的页面，留给您想弄明白的那一天。

## 为什么影片要等一会儿才开始？

多半是因为服务器正在转换它。您的电视或手机无法原样播放存储的那个文件，所以服务器一边播一边转换，开头几秒就花在准备上。几乎立刻开始的影片，是原样发送的。

在播放器里打开**流信息**（(i) 按钮），它会逐条音视频轨说明是哪一种情况，以及原因。如果只有某一部每次都慢，其他的都正常，那多半是文件本身的问题，运行 Evey 的人可以在**管理 → 媒体健康**里检查。

延伸阅读：[播放方式是如何决定的](../playback/how-playback-is-decided.md#reading-stream-info)，以及写给运行服务器的人的[媒体健康](../runbooks/media-health.md)。

## 为什么我不在家时手机上的画面没那么清晰？

因为家外的观众受一个上限约束。运行 Evey 的人可以在**管理 → 转码**里设两个限制：一个对所有人生效，另一个更低、只对本地网络之外的观众生效，好让影片在移动网络上也能继续播放。每个账户还可以有自己的**最大码率**。超过上限的影片会被转换到上限以内，细节也随之少了一些。

您这边无需选择：Evey 从不让您挑画质。**流信息**会显示生效的是哪个限制。

延伸阅读：[编码的内容](../playback/transcoding.md#what-is-encoded)和[管理员可以按账户限制什么](../administration/users.md#what-an-administrator-can-restrict-per-account)。

## 为什么声音是另一种语言？

您在播放器设置菜单里手动选的音轨，对这部影片永远优先。否则播放器会依次采用**设置 → 播放 → 默认音频语言**里设定的语言、文件标记为默认的音轨、第一条音轨。在那里设一次语言，每部影片都会照此选择。字幕同理，对应**默认字幕语言**。

延伸阅读：[播放哪条音轨](../playback/audio.md#which-track-plays)。

## 能在我的电视上用吗？

可以，三种方式任选其一：

- **Android TV 或 Google TV** 运行为遥控器设计的 Evey 应用。登录画面上的**快速连接**会显示一个代码，您在手机或电脑上确认即可，不必用遥控器输入密码。
- **带网页浏览器的电视**在服务器地址后面加上 `/tv`，就能打开同样风格的界面。
- **Chromecast**，或内置 Chromecast 的电视，通过网页或 Android 播放器里的投屏按钮接收画面。

延伸阅读：[连接应用](apps.md#quick-connect-signing-in-a-tv-without-typing-a-password)和[投屏](../playback/casting.md)。

## 在火车上没有网络也能看吗？

用 Android 应用可以。在某部影片或某一集上，应用可以把一份副本保存在手机里（**下载**），30 天内无需联系服务器即可播放。运行 Evey 的人开启相应选项后，对于手机放不下的大文件，应用还会提供一份更小的副本。儿童个人资料打不开超过其年龄限制的下载内容，即使是别的个人资料下载的也不行。

延伸阅读：[每个应用各自增加了什么](apps.md#what-each-app-adds)。

## 能和住在别处的朋友一起看电影吗？

可以。在网页播放器或 Android 应用里开始播放，按**一起看**，您会得到一个六位代码。朋友输入这个代码，可以用自己的账户，也可以在没有账户的情况下用登录页上的**一起看**加入。每个人在自己的屏幕上看到同一时刻，播放的是适合自己设备的版本。

延伸阅读：[一起看](../playback/watching-together.md)。

## 怎样让朋友访问，又不把整个片库都开放？

在**管理 → 用户**里创建一个邀请链接，并把它限制在这个人可以看的媒体库：其他媒体库对这个人到处都不可见，搜索里也没有。您还可以限制对方收到的画质（**最大码率**）以及同时播放的屏幕数。只想分享一部影片的话，影片页面上的**公开下载链接**让拿到链接的任何人在 48 小时内无需账户下载该文件。

延伸阅读：[创建账户](../administration/users.md#create-an-account)和[公开下载链接](../administration/users.md#public-download-links)。

## 为什么某部影片没有海报，或者海报不对？

因为文件名没有指向正确的影片。对电影来说年份最重要（`The Mirror (1999)`）；对剧集来说是季数和集数（`S01E05`）。要修正某一部，打开它，选择**编辑元数据**，再选**在 TMDB 上识别**，挑出正确的匹配。新增、改名或删除的文件几分钟内会自动出现；媒体库那一行的**扫描**可以立即触发。

延伸阅读：[文件如何命名才能被识别](../administration/libraries.md#name-files-so-they-are-recognised)和[修正错误或缺失的影片信息](../administration/libraries.md#fix-a-wrong-or-missing-title)。

## 字幕显示正在准备中，是出问题了吗？

没有。某条字幕第一次被任何人选中时，服务器要先把它从文件里提取出来；视频继续播放，字幕准备好后自动出现。每条字幕轨只发生一次。如果这条提示停留了好几分钟，说明文件里没有这条字幕的索引，服务器要把文件完整读一遍，也只读这一次。

延伸阅读：[字幕第一次显示时](../playback/subtitles.md#the-first-time-a-subtitle-is-shown)。

## 所有人同时都卡，这是为什么？

服务器同时只转换有限数量的视频，这个数量是它在自己的硬件上实测得出的。空间不够时，它先降低新开流的画质，再把它转到处理器上，最后才显示**服务器正忙于转码其他流**。原样发送的影片不占名额，所以与家里设备匹配的片库很少碰到上限。运行 Evey 的人可以在**管理 → 系统健康**里查看负载。

延伸阅读：[分享容量](../playback/transcoding.md#sharing-the-capacity)。

## 我的影片或观看记录会离开家吗？

不会。应用只与您的 Evey 服务器通信，不与项目方运营的任何东西通信。您浏览、播放和请求的内容都留在那台服务器上，谁能读取由运行它的人决定。例外都在意料之中：从公开来源获取的海报、加载接收器页面的 Chromecast、您自己打开的链接。

延伸阅读：[隐私政策](../privacy.md)。

## 怎样更新才不会弄坏东西？

给运行服务器的人：在放着 compose 文件的目录里执行

```bash
docker compose pull && docker compose up -d
```

更新就这么多。新版本需要修改数据库时，会先在 `./evey-data/backups/` 里保存一份副本。有新版本时 Evey 会在管理面板里提示；它从不自行更新。

延伸阅读：[更新 Evey](../backups.md#updating-evey)。

## 我忘记密码了

如果登录页显示**忘记密码？**，就用它：重置链接会发到您的邮箱。只有运行 Evey 的人开启了**密码找回**并配置了邮件，这个链接才会出现。否则请找这个人：在**管理 → 用户**里，**编辑用户**有一个**新密码**栏。万不得已，当丢失的是管理员自己的密码时，在服务器上运行 `evey admin reset-password` 会打印一个新密码。

延伸阅读：[邮件和通知](../notifications.md)和[给用户设置新密码](../runbooks/recovery.md#give-a-user-a-new-password)。
