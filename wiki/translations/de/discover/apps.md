# Auf jedem Bildschirm

Ein Server, eine Bibliothek, überall dieselben Fortsetzungspunkte. Jede App
spricht mit Ihrem eigenen Server: Sie geben seine Adresse einmal ein, melden
sich an, wählen ein Profil, und Sie sind zu Hause.

## Im Browser

Die Web-App wird vom Server selbst ausgeliefert, unter der Adresse, die Sie nach
der Installation öffnen: Auf dem Computer ist nichts zu installieren. Sie bietet
das ganze Erlebnis - Filme, Serien, Musik, Fotos, Zusammen schauen - und für
Administratoren den Administrationsbereich. Am Computer reagiert der Player auf
die Tastatur (drücken Sie `?`, um die Kürzel zu sehen).

## Auf einem Android-Handy oder -Tablet

Die Android-App ergänzt, was ein Handy gut kann:

- **Downloads** zum Offline-Schauen, mit einer kleineren Kopie, die der Server
  vorbereitet, wenn das Original nicht passen würde;
- **Streamen** auf einen Chromecast direkt aus dem Player;
- **einen Schnellverbindungs-Code scannen**, um einen Fernseher anzumelden, ohne
  mit der Fernbedienung ein Passwort einzutippen;
- **Push-Benachrichtigungen**, wenn neue Filme, Folgen oder Musik ankommen, in
  der Stufe, die Sie für jedes wählen, sofern der Server dafür eingerichtet ist.

## Auf Android TV

Die TV-App ist für die Fernbedienung gemacht: große Poster, Reihen, die man mit
den Pfeiltasten durchläuft, ein Player, dessen Bedienelemente sich zurückhalten.
Zum Anmelden muss kein Passwort eingetippt werden: Der Fernseher zeigt einen
**Schnellverbindungs**-Code (und einen QR-Code), Sie bestätigen ihn auf einem
Handy oder Computer, auf dem Sie schon angemeldet sind, und der Fernseher ist
drin.

## Auf einem Chromecast

Aus dem Web-Player in Chrome oder aus der Android-App schickt die Taste
**Streamen** den Film an einen Chromecast oder einen Fernseher mit
integriertem Chromecast. Der Server steuert ihn direkt mit seinem eigenen
Empfänger, sodass das, was auf dem Fernseher läuft, für den Fernseher gewählt
wird - seine Codecs, seinen Bildschirm, seine Verbindung - und nicht für das
Handy, das es geschickt hat.

## Von einer Evey-App zur anderen

**Abspielen auf** schickt, was Sie gerade schauen, an eine andere Evey-App, die
im selben Konto geöffnet ist - die TV-App im Wohnzimmer, das Handy auf dem
Schreibtisch - und dort geht es weiter. Die Taste listet die Geräte auf, die
gerade online sind.

## Welches spielt am besten?

Der Server prüft, was jedes Gerät dekodieren kann, und passt sich an: Derselbe
Film kann unverändert an den Fernseher gehen und für ein altes Handy
umgewandelt werden. Die Entscheidung und ihre Gründe sehen Sie im Feld
**Stream-Info** des Players.
